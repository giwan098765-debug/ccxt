# 📈 AI 주식 스캐너

**스캔 시작** 버튼 하나로 시장 전체를 훑어서 다음을 종합 분석하고, 잘하는 분야별로 종목을 나눠 보여줍니다.

| 분석 영역 | 내용 |
|---|---|
| 차트 모양 | 이평 정배열/역배열, 일목 구름대 위치, 박스권, 52주 고점 대비, 쌍바닥(W) 감지 |
| 캔들 | 망치형·상승장악형·샛별형·적삼병·장대양봉·관통형·잉태형 / 유성형·하락장악형·석별형·흑운형 등 14종 |
| 상단지표 | 이동평균(5/20/60/120/240), 볼린저밴드, 일목균형표 |
| 보조지표 | RSI, MACD, 스토캐스틱, ADX/DMI, ATR, OBV, MFI, CCI, 거래량 배수 |
| 매물대 | 가격대별 거래량(Volume Profile), POC, 가치영역 70%, 위 저항대/아래 지지대, 현재가 위 매물 비중 |
| 재무제표 | PER·PBR·ROE·영업이익률·매출/이익 성장률·부채비율·분기 영업이익 흑자전환 → 0~100점 |

## 유형별 분류 (탭)

- 🚀 **이번주 급등주**: 이번 주 +15%↑ (기준 조절 가능) 오른 종목 + 상한가 횟수 + **급등 근거 자동 분해**
  (급등일 거래량, 신고가/박스권 돌파, 장대양봉, 매물대 돌파, 급등 전 밴드 수렴·OBV 매집, AI가 급등 전날 예측했던 확률, 재무, 급등 후 통계적 흐름)
- 🤖 **AI 급등 후보**: 향후 5거래일 안에 +15% 갈 확률이 평균의 1.5배 이상인 종목
- 📈 돌파형 · ↩️ 반등형 · 📊 추세추종형 · 🌀 눌림목형 · 🎯 수렴(스퀴즈)형 · 🔋 거래량 급증형 · 💎 재무우량형
- 🏆 전체 랭킹 (종합점수)

## "몇 % 오를 수 있고, 성공확률은 몇 %?" 는 어떻게 계산하나

추측이 아니라 **실제 과거 차트로 백테스트**합니다.

1. **목표가 / 손절가**: 매물대(위 저항대·아래 지지대)와 ATR(변동성)로 종목마다 계산. 손익비는 최소 1.5:1.
2. **성공확률**: 지금과 같은 셋업(돌파/반등/눌림목 …)이 이 종목에서 과거에 나왔던 모든 날에 똑같이 진입했다고 가정하고,
   10거래일 안에 **손절가보다 목표가에 먼저 닿은 비율**. 표본이 적으면 스캔한 전체 종목의 같은 셋업 통계로 보정(베이지안 축소).
   비교용으로 "아무 신호 없이 매일 샀을 때" 기준 확률도 함께 보여줍니다.
3. **기대값(EV)**: 성공확률 × 목표수익 − 실패확률 × 손절폭.
4. **AI 급등 모델**: 스캔한 모든 종목의 과거 2년치 일봉 20개 특징(거래량, 밴드폭 수렴, OBV, 이격도, 고점 대비 위치 …)으로
   로지스틱 회귀를 학습해 "5거래일 내 +15% 도달 확률"을 예측합니다. **시간순으로 최근 20% 구간은 학습에서 빼고 검증**해서
   AUC와 상위 10% 적중률을 화면 상단에 그대로 공개합니다. 종목마다 어떤 요인이 확률을 올리고 내렸는지도 보여줍니다.
5. **Claude 리포트(선택)**: `ANTHROPIC_API_KEY`가 있으면 위의 모든 수치를 근거로 Claude가 애널리스트 리포트(결론·근거·매매 시나리오·리스크)를 씁니다.
   엔진이 계산한 숫자만 쓰도록 지시합니다.

## 설치 · 실행

```bash
cd stock-ai-scanner
pip install -r requirements.txt
streamlit run app.py            # 웹 앱 (브라우저가 열림)
python scan.py --market KOSDAQ --limit 500   # 터미널 버전
python scan.py --demo           # 인터넷 없이 합성 데이터로 동작 확인
pytest -q tests                 # 테스트
```

선택: `export ANTHROPIC_API_KEY=...` → 상세 화면의 **AI 리포트 생성** 버튼 활성화 (모델은 `STOCK_SCANNER_MODEL`로 변경 가능, 기본 `claude-opus-5-5`).

## 데이터 소스

- 한국(KOSPI/KOSDAQ): [FinanceDataReader](https://github.com/FinanceData/FinanceDataReader) (KRX 종목목록 + 일봉), 실패 시 yfinance(`.KS`/`.KQ`)
- 미국(S&P500): yfinance
- 재무: yfinance (`info`, 분기 손익계산서) — 시간이 걸려서 종합점수 상위 60개 + 이번주 급등주만 조회합니다.
- 결과는 `~/.cache/stock_ai_scanner` 에 캐시됩니다(시세 3시간, 재무 24시간).
- 종목 수가 많을수록 오래 걸립니다 (KRX 400종목 ≈ 1~3분, 전체 2,500종목 ≈ 10분 이상).

## 구조

```
scanner/
  data.py            시세·종목·재무 수집 (실제/데모)
  indicators.py      상단지표 + 보조지표
  candles.py         캔들 패턴 14종
  patterns.py        셋업(매매 자리) 8종 + 차트 모양 + 쌍바닥

  fundamentals.py    재무 점수
  probability.py     목표/손절 백테스트, 베이지안 보정, AI 급등 모델
  engine.py          스캔 파이프라인, 유형별 분류, 급등 근거 분석
  ai_report.py       Claude 리포트
app.py               Streamlit UI
scan.py              CLI
```

## ⚠️ 주의

확률·목표가는 **과거 통계에 기반한 추정치**이고 미래 수익을 보장하지 않습니다. 급등주는 변동성이 매우 크며,
뉴스·공시·수급 같은 차트 밖 재료는 반영하지 않습니다. 투자 판단과 책임은 본인에게 있습니다.
